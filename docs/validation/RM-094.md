## Real reflection and bounded rendering

Installed Three Reflector renders the current room from a reflected camera. One scene-owned512×512 half-float target, MSAA0 and one live plane serve all registered mirror surfaces. Selection has priority among front-facing/frustum-visible surfaces, followed by distance/stable identity. Other faces retain the existing glossy environment fallback. Switching active mirrors reuses the target; at most one auxiliary scene pass occurs per demand frame. Editor selection overlays are hidden and restored around that pass; the reflector hides itself, preventing recursive mirrors. Actual piece/hinged-leaf transforms drive the registered face.

No new timer, perpetual frame owner, postprocessing, remote texture/model, dependency or renderer. Rear/offscreen/hidden faces skip the pass. Failure restores target/XR/shadow state and disables the optional plane, retaining glossy fallback; unregister/dispose retires the one target/material/plane with scene ownership. Exports contain the actual frame/stand/single mirrored panel and safe reflective material, with no live-target/export lifecycle added. This is a design preview, not photometric/installation or guaranteed physical-device performance evidence.
