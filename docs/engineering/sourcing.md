No model substitution, SDK, retry, continuation, database, service or account change. Actual model/tool/account compatibility is unperformed. These support the prepared wire shape, not a real merchant-quality or spending guarantee. Tests inject all transport responses with synthetic credentials and deny actual external requests.

Strict decoding admits web action metadata only for the trusted sourcing format; existing photo/assistant calls still reject it. Keep a bounded action count, source list and explicitly opened URLs. A snippet/citation alone cannot establish a price. Search/discovery pages, missing page openings, mismatched source URLs, conditional/member/from/unknown prices, unsupported fields/units/market/currency and unrelated categories become leads or reject. Source pages/snippets/model prose are untrusted data: they have no command authority. Price parsing retains exact variant/pack/yield/components/tax/availability/lead time; missing essential information stays a lead. The application owns calculations.

The server stamps observation time, opaque offer identity and a supplier identity from hostname plus seller name. Different sellers on one marketplace domain remain different; same identified seller can share an order group. Actual basket, fulfilment/access/destination eligibility still needs review. New supplier delivery starts unpriced unless separately evidenced or explicitly entered. No copied prior delivery fee, currency conversion or automatic stock refresh. Source URLs are public HTTPS-shaped links without credentials, ports or local hosts, displayed as plain links without remote images or prefetch. Schema validation and page-opening metadata do not certify a publication’s accuracy or storage rights.
