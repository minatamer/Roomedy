# Official market-search API reference —30 October2026

Each image result includes canonical image URL, source website URL, optional thumbnail and caption. Search context size determines available evidence detail. [Responses create](https://developers.openai.com/api/reference/cli/resources/responses/methods/create) defines max_tool_calls across built-in calls.

[Responses items](https://developers.openai.com/api/reference/resources/responses/methods/create) describes completed/failed/incomplete search actions and optional action metadata. Optional tool metadata can be absent/nullable; failed lookups grant no evidence but cannot erase successful stores. Bounded url_citation annotations also identify actual cited merchant results. Comparison listings/images may use cited product evidence; accepted estimate offers still require opened exact-page evidence.

[GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) supports low effort; [deployment guidance](https://developers.openai.com/api/docs/guides/deployment-checklist) recommends low for extraction/routing. Select low for sourcing/image lookup only and validate the actual US matrix; keep model, chat/photo effort and physical/monetary authority unchanged. This is a representative live latency/quality check, not a claim that all future retailers or variants are available.

Actual product-page probes confirmed published image metadata from both known US product links. The final fallback pins public IPv4 DNS into a fresh TLS-verified connection with finite header/body/time/fragment limits and no redirects/auth/cookies. It retrieves image metadata only, never prices or financial authority. Earlier no-generic-fetch design was superseded by this scoped public product-image fallback after model-only media proved unreliable.
