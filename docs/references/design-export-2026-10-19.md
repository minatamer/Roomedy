# Design-export primary sources —19 October2026

[Three GLTFExporter](https://threejs.org/docs/pages/GLTFExporter.html): existing addon supports binary GLB containing geometry/materials/textures, parseAsync and maxTextureSize. Inspected installed Three0.186.1 implementation/types before use; model generation stays within existing Roomedy geometry/representation authority. GLB is a3D interchange output; semantic project remains necessary for Roomedy Current/Before/provenance/import.

[PDF-LIB](https://pdf-lib.js.org/): browser-compatible TypeScript/JavaScript PDF generation with embedded JPEG images/pages, no native dependency. Only generated document/page authoring is selected, not arbitrary PDF loading/parsing/upload. Pin lazy dependency before runtime use. Page canvases use Roomedy’s actual Arial/Georgia browser font stack and warm palette, encoding high-quality fixed-resolution pages. Rasterized presentation text is a deliberate implementation tradeoff; no claim of searchable/vector/CAD/PDF-A output or native/physical acceptance. [PDF artifact workflow](C:/Users/minat/.codex/plugins/cache/openai-primary-runtime/pdf/26.1017.11052/skills/pdf/SKILL.md) requires first-authoring marker and rendered page inspection; bundled Poppler/Python are development evidence only.

Owner-requested format research: [SketchUp GLB workflow](https://help.sketchup.com/en/sketchup/working-gltf-files) documents single-file models, PBR textures and GLB import. [Rhino8 file formats](https://docs.mcneel.com/rhino/8/help/en-us/fileio/_index_of_import_export_file_types.htm) lists GLB and OBJ; [Rhino OBJ details](https://docs.mcneel.com/rhino/7mac/help/en-us/fileio/wavefront_obj_import_export.htm) describe mesh vertices/UVs/normals and companion MTL material definitions. Both serve designer interchange, with application/version-specific support. Recommendation: GLB for appearance, OBJ+MTL/textures ZIP for mesh compatibility, PDF for client presentation, JSON for reopening Roomedy semantics. These are mesh exports, not editable parametric CAD/BIM. [Three OBJExporter](https://threejs.org/docs/pages/OBJExporter.html) omits MTL, so do not claim its geometry-only output preserves materials; use bounded geometry serialization plus explicit MTL/local diffuse textures and existing pinned Three bundled fflate ZIP. Advanced PBR properties remain a GLB advantage. No market-share statistics or universal importer compatibility inferred.
